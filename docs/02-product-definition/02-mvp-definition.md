# Purpose

This document defines the Minimum Viable Product (MVP) for CareerOS.

The MVP represents the smallest version of the product that delivers meaningful value to users while validating the core product assumptions.

Features outside this scope will be considered for future releases.

---

# MVP Goal

Enable early-career software professionals to organize their career journey, track job applications, understand their progress, and receive personalized guidance within a single platform.

---

# MVP Objectives

The MVP should allow users to:

- Create and manage a career profile.
- Upload and manage resumes.
- Save and organize job opportunities.
- Track job applications.
- Record interview information.
- Receive AI-powered career guidance.
- View career progress from a single dashboard.

---

# Success Criteria

The MVP is successful if users can:

- Organize all career information in one place.
- Track applications without spreadsheets.
- Understand current career status.
- Receive useful personalized recommendations.
- Return regularly to update their progress.

# Excluded Features

The MVP will not include:

- Recruiter portal
- Company portal
- Team collaboration
- Social networking
- Messaging
- Mobile application
- Public user profiles
- Salary benchmarking
- Learning platform
- Advanced analytics
- Subscription billing
- Multi-language support

---

# MVP Assumptions

The MVP assumes:

- Users prefer one unified workspace.
- AI guidance increases user engagement.
- Browser-assisted capture reduces manual work.
- Users will update career information regularly.

---

# Constraints

- Single user workspace.
- Web application only.
- English language.
- Manual onboarding supported.
- Limited third-party integrations.

---

# Risks

- Low user engagement after onboarding.
- Incomplete career information.
- AI recommendations lacking context.
- Browser integration limitations.

---

# Validation Questions

The MVP should answer:

- Do users return after onboarding?
- Do users consistently track applications?
- Do AI recommendations influence user actions?
- Does the dashboard improve career visibility?
- Does CareerOS replace spreadsheets and notes?

---

# Design Implications

- Prioritize simplicity.
- Optimize onboarding.
- Reduce manual work.
- Deliver value within the first session.
- Keep every feature aligned with the core product goal.
