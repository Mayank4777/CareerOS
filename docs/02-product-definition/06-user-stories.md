# User Stories

**Product:** CareerOS  
**Document Version:** 1.0  
**Status:** Approved  
**Last Updated:** July 29, 2026

# Purpose

This document defines the user stories for the CareerOS MVP.

Each story represents a user need and serves as the foundation for development, testing, and sprint planning.

---

# Story Format

Every user story follows this format:

> As a <user>, I want <goal>, so that <benefit>.

---

# EPIC-01 — Authentication & User Management

### US-001

**As a** new user

**I want** to create an account

**So that** I can access CareerOS.

---

### US-002

**As a** registered user

**I want** to log in securely

**So that** I can access my career workspace.

---

### US-003

**As a** user

**I want** to reset my password

**So that** I can recover my account.

---

### US-004

**As a** user

**I want** to manage my profile

**So that** my information stays up to date.
