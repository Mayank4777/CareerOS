# Purpose

This document describes how the target user progresses through their job search journey and identifies where CareerOS can reduce friction, provide insights, and improve decision-making.

Rather than replacing existing career platforms, CareerOS integrates into the user's existing workflow and acts as the intelligence layer across the entire journey.

---

# Journey Overview

The journey begins when a student decides to actively search for internships or full-time software engineering opportunities and continues until they secure a job offer and prepare for onboarding.

CareerOS supports the user throughout this journey by collecting career information, analyzing progress, and recommending the next best action.

---

# Stage 1 — Career Preparation

## User Goal

Prepare for the job market.

### User Activities

- Build technical skills.
- Complete projects.
- Participate in hackathons.
- Build a GitHub profile.
- Create a resume.
- Create or update LinkedIn.

### User Pain Points

- Unsure if skills are sufficient.
- Doesn't know what to prioritize.
- Doesn't know when to start applying.

### CareerOS Role

- Build the initial career profile.
- Import resume and GitHub.
- Establish baseline career readiness.
- Identify initial skill gaps.

---

# Stage 2 — Job Discovery

## User Goal

Find relevant job opportunities.

### User Activities

- Browse LinkedIn.
- Browse Naukri.
- Browse Indeed.
- Browse Internshala.
- Visit company career pages.

### User Pain Points

- Too many opportunities.
- Difficult to compare jobs.
- Frequently forget saved opportunities.

### CareerOS Role

- Browser-assisted job capture.
- Save selected opportunities.
- Organize opportunities.
- Extract important job details.

---

# Stage 3 — Application

## User Goal

Submit quality applications.

### User Activities

- Customize resume.
- Apply through company portals.
- Upload documents.
- Submit applications.

### User Pain Points

- Applying manually is repetitive.
- Resume versions become confusing.
- No history of previous applications.

### CareerOS Role

- Track applications automatically whenever possible.
- Maintain application history.
- Associate applications with resume versions.
- Store job descriptions for future reference.

---

# Stage 4 — Waiting Period

## User Goal

Continue improving while waiting.

### User Activities

- Apply to additional companies.
- Study DSA.
- Build projects.
- Learn new technologies.

### User Pain Points

- Doesn't know what to improve.
- Doesn't know whether progress is being made.

### CareerOS Role

- Recommend learning priorities.
- Track improvement over time.
- Highlight weak areas.
- Suggest next actions.

---

# Stage 5 — Assessments & Interviews

## User Goal

Perform well in hiring evaluations.

### User Activities

- Online assessments.
- Technical interviews.
- HR interviews.
- System design discussions (where applicable).

### User Pain Points

- Poor preparation.
- Forgetting previous interview experiences.
- Repeating mistakes.

### CareerOS Role

- Store interview history.
- Record interview outcomes.
- Capture personal notes.
- Identify recurring weaknesses.
- Recommend focused preparation.

---

# Stage 6 — Offer Decision

## User Goal

Evaluate job offers.

### User Activities

- Compare multiple offers.
- Review salary and role.
- Consider company growth.
- Decide whether to accept.

### User Pain Points

- Difficulty comparing opportunities.
- Emotional decision-making.

### CareerOS Role

- Organize offer information.
- Help compare opportunities.
- Preserve decision history.

---

# Stage 7 — Continuous Career Growth

## User Goal

Continue improving after getting hired.

### User Activities

- Learn new technologies.
- Update achievements.
- Prepare for future opportunities.

### User Pain Points

- Career tracking usually stops after employment.

### CareerOS Role

- Continue maintaining career history.
- Track skills and achievements.
- Prepare for future role transitions.

# Key Product Opportunities

CareerOS provides the greatest value when it:

- Reduces manual work.
- Captures information at the moment it is created.
- Connects information across different platforms.
- Detects patterns that users cannot easily identify.
- Recommends actionable next steps.

The product should focus on helping users make better decisions rather than collecting more data.

---

# Design Implications

This journey directly influences product design:

- Browser-assisted capture should occur during job discovery.
- Manual data entry should be minimized throughout the product.
- Dashboards should emphasize current priorities.
- Career recommendations should evolve as the user's journey progresses.
- Every interaction should contribute to a persistent career history.
- Users should never need to enter the same information twice.

---

# Success Indicators

CareerOS successfully supports the journey when users:

- Spend less time organizing information.
- Spend more time improving relevant skills.
- Understand where they are losing opportunities.
- Know what to work on next.
- Feel more confident throughout the hiring process.

---

# Summary

CareerOS accompanies users throughout their career journey rather than assisting with only one isolated task.

Its responsibility is to continuously collect relevant career information, understand user progress, and guide better career decisions at every stage of the journey.
